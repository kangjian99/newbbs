# 巷议

一处安静、清楚的中文讨论区。按版块发帖，回复可以层层嵌套。界面、校验和分页都是简体中文，时间按北京时间显示。

## 本地运行

需要 Node.js 22。

```bash
npm install
cp .env.example .env.local
npm run dev
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

不填写 `DATABASE_URL` 时，数据放在本地 SQLite 文件 `data/forum.db`（已加入 `.gitignore`）。填写之后，应用在启动时连接 Postgres。开发模式下空库会写入演示数据；生产模式（`next start`）默认不写入。

生产构建：

```bash
npm run build
npm start
```

## 环境变量

只在 `.env.local` 里填写真实值。`.env.example` 只有占位符，不要把连接串或口令提交进仓库。

| 变量 | 作用 |
| --- | --- |
| `DATABASE_URL` | 运行时连接。Neon 请用带 `-pooler` 的地址。留空则使用 SQLite。 |
| `DATABASE_URL_DIRECT` | 迁移用的非 pooler 直连。不填则迁移也走 `DATABASE_URL`。也认 `DIRECT_URL`。 |
| `ADMIN_SETUP_TOKEN` | 至少 16 位的随机口令。库里还没有管理员时，注册页会多出「管理员口令」一栏，填对的账号成为管理员。已有管理员之后不再生效。 |
| `SEED_DEMO` | 空库是否写入演示数据。不填时开发模式写入、生产模式不写入。设为 `true` 或 `false` 可以强制。 |
| `TRUSTED_PROXY_HOPS` | 应用前面有几层会追加 `X-Forwarded-For` 的反向代理，默认 `1`。限流按从右数第这么多个地址认定客户端 IP。应用不要直接暴露在公网上，否则客户端可以自己伪造这个头。 |
| `AUTH_SECRET` | 当前会话不依赖它。生产环境可以留一长串随机值，供以后扩展。 |

Neon 项目（非机密）：`web-bbs`（id `rapid-bar-49860901`），区域 AWS ap-southeast-1，数据库 `neondb`，角色 `neondb_owner`。

`npm run db:migrate` 会按顺序执行 `migrations/*.sql`。应用启动时也会做同样的事：有直连地址就用直连跑迁移，页面请求走连接池。`npm run db:reset` 只删除本地 SQLite 文件，不会清空远程 Postgres。

## 第一位管理员怎么登录

有两条路，可以同时用。

**演示账号（仅开发模式默认）。** 开发模式下空库会种入管理员：

- 用户名 `admin`
- 密码 `admin123456`
- 邮箱 `admin@xiangyi.local`

其他演示账号的密码都是 `demo123456`：版主 `lin`，会员 `he`、`su`、`zhao`、`miao`、`qiao`、`guang`。所有演示账号都带有「必须修改密码」标记，登录后顶部有提示。开发模式下，admin 改密码之前登录页会显示这些口令；生产模式下登录页从不显示。这些口令只适合本地和演示，生产环境如果用 `SEED_DEMO=true` 强制写入，务必立刻全部改掉。

**用口令注册第一位管理员。** 注册不验证邮箱，所以不能靠邮箱认定管理员。在 `.env.local` 设置 `ADMIN_SETUP_TOKEN`（例如 `openssl rand -base64 24` 生成），库里还没有管理员时，注册页会出现「管理员口令」一栏，填对的账号直接成为管理员。有了管理员之后，这个口令不再生效，可以从环境变量里删掉。

生产模式默认就是空论坛。没有设置 `ADMIN_SETUP_TOKEN`、库里也没有管理员时，注册页会提示先配置这个变量。

## 注册防滥用

没有配置发信服务，所以注册不走邮箱验证，填完就可以发言。挡住机器注册靠这几件事一起做：

- 本地 SVG 加法验证码，答案只存哈希，十分钟有效，用过即废。
- 表单令牌：发出后至少 2 秒、至多 2 小时才能提交。
- 蜜罐字段「传真」。真人看不到，填了就拒绝。
- 按 IP 限制注册、登录失败和验证码刷新。登录失败按「IP」和「IP 加账号」封锁；同一账号的失败只会让后续尝试变慢，不会把账号锁死。IP 取自可信代理追加的 `X-Forwarded-For`，见 `TRUSTED_PROXY_HOPS`。
- 密码至少 8 位，要有字母和数字，不能是常见密码，也不能包含用户名。
- 拒绝一批一次性邮箱域名。
- 登录失败时，即使用户不存在也会做一次假的密码比对，并返回同一句错误。

## 功能

- 注册、登录、退出。个人资料可以改昵称、简介和头像颜色。
- 版块列表。管理员可以新建版块。
- 发帖、回复、编辑自己的发言、软删除。正文支持安全的 Markdown。
- 楼中楼。对楼主的直接回复分页，下面的回复整枝带上。默认收起较深的层，可以展开。嵌套到第 8 层为止，更深的缩进会停住，避免手机上被挤出屏幕。
- 角色：会员、版主、管理员。版主和管理员可以置顶、锁定、移动主题，隐藏或删除发言，处理举报。
- 首页按最后回复排序，登录后能看未读，也能看到上次访问以来有更新的主题数。
- 搜索、会员列表、会员主页、站内回复通知。
- 面包屑、分页、北京时间。

## 结构

一个 Next.js 应用，服务端动作直接读写数据库，没有单独的 API 服务。

- `src/app`：页面。
- `src/server`：查询、写入和演示数据。
- `src/lib/db.ts`：Postgres（`pg`）或 SQLite（`better-sqlite3`）。SQL 里写 `?`，Postgres 会换成 `$1`。
- `migrations`：两边都能执行的建表语句。时间用毫秒整数，开关用 0/1。
- 会话是 httpOnly cookie，库存的是令牌哈希，不是 JWT。

启动时如果用户表是空的，并且没有把 `SEED_DEMO` 设为 `false`，会写入中文版块、主题和上面的演示账号。
